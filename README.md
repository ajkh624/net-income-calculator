# 재환님의 실수령액 · 절세 전략 계산기

두 곳의 근로소득과 부업 수입을 합산해 월 실수령액, 내년 종합소득세, 절세 전략을 한 화면에서 보는 개인 재무 대시보드.

🔗 **Live**: https://ajkh624.github.io/net-income-calculator/

## 기능
- 회사별(미메틱스/피앤피) 월 실수령액 상세
- 부업 4종(블로그/강의/타운카/기타) 비용률·순익 시뮬레이션
- 내년 5월 종합소득세 예측 및 월 적립 권장액
- 월세(세액공제) vs 전세대출(원리금 40% 소득공제) 절세액·세후 주거비 비교
- 절세 전략 제안 + 추가 부업 시뮬레이션 차트

## 사용
`index.html`을 브라우저로 열거나 GitHub Pages URL 접속.
